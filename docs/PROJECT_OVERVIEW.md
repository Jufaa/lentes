# Descripción general del proyecto

CyberSpace AR es una experiencia educativa para SPECS que hace visibles los procesos de redes y ciberseguridad mediante un laboratorio espacial. El escenario principal consiste en observar tráfico legítimo, simular un incidente abstracto, aplicar una defensa de firewall y verificar que la comunicación legítima siga funcionando.

## Público

Estudiantes de Ciencias de la Computación, redes y ciberseguridad; docentes y profesionales de IT.

## Objetivo del MVP

La Lens final debería mostrar un laboratorio predefinido, permitir inspeccionar dispositivos, visualizar tráfico legítimo y tráfico no autorizado simulado, aplicar una defensa efectiva, evaluar el desafío Protect the Server, explicar el resultado y reiniciar el laboratorio.

## Alcance actual

Este repositorio contiene la planificación y el primer incremento del modelo de red del Core. Todavía no contiene un proyecto de Lens Studio.

## Límite entre entornos

La lógica del Core y sus pruebas automatizadas pueden desarrollarse en Arch Linux. La validación con Lens Studio, SPECS Preview, CLAD, Lens Studio MCP y LEAF requiere un entorno compatible con Lens Studio y sigue pendiente.
